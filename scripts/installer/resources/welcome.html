TickTick Live — Voice Task Manager

Говорите задачи голосом — они появляются карточками прямо во время речи и одной кнопкой уходят во «Входящие» TickTick.

Программа установится в папку «Программы» и запустится. Она живёт в верхнем меню, вызывается сочетанием ⌥⇧R (меняется в настройках).

После первого запуска откройте настройки (шестерёнка) и укажите:

  • ключ Gemini Live API — aistudio.google.com → Get API key;
  • токен TickTick Open API — developer.ticktick.com.

Requires macOS 14 or later. Speak any language; the interface supports EN, UK, RU, ES, PL, DE, IT.
