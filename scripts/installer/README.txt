TickTick Live — Voice Task Manager

УСТАНОВКА
1. Перетащите «TickTick Live» на папку «Applications» (Программы).
2. Запустите приложение из «Программ». Если macOS скажет, что разработчик не подтверждён:
   правый клик по приложению → «Открыть» → «Открыть» (нужно один раз),
   или Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть».
3. Откройте настройки (шестерёнка) и укажите ключ Gemini Live API и токен TickTick.
4. Нажмите ⌥⇧R (или на микрофон) и говорите задачи.

INSTALL
1. Drag "TickTick Live" onto the Applications folder.
2. Open it from Applications (first time: right-click → Open).
3. Open Settings (gear) and enter your Gemini Live API key and TickTick token.
4. Press ⌥⇧R (or click the mic) and speak your tasks.
