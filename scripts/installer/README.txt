Dictate for TickTick
Unofficial app. Not affiliated with TickTick (Appest Inc.) or Doist.

INSTALL
1. Drag "Dictate for TickTick" onto the Applications folder.
2. Open it from Applications. The first time, macOS says it can't verify the app:
   open System Settings → Privacy & Security, scroll down, click "Open Anyway".
   You only need to do this once.
3. Open Settings (gear) and enter your Gemini Live API key and TickTick token.
4. Press ⌥⇧R (or click the mic) and speak your tasks.

УСТАНОВКА
1. Перетащите «Dictate for TickTick» на папку «Applications» (Программы).
2. Запустите приложение из «Программ». В первый раз macOS скажет, что не может проверить приложение:
   откройте Системные настройки → Конфиденциальность и безопасность, прокрутите вниз и нажмите «Всё равно открыть».
   Это нужно сделать один раз.
3. Откройте настройки (шестерёнка) и укажите ключ Gemini Live API и токен TickTick.
4. Нажмите ⌥⇧R (или на микрофон) и говорите задачи.
